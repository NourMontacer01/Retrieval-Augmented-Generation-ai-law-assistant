# ⚖️ Recueil de conformité

Assistant de recherche sur le droit européen des données et de l'IA (RGPD, AI Act, directive
ePrivacy, Data Act). Chaque passage est cité à l'article près, avec sa nature juridique, et la
phrase qui répond à la question est surlignée.

La recherche tourne entièrement dans le navigateur : le modèle d'embeddings
(multilingual-e5-base) est chargé à la première visite, puis gardé en cache.

Code source, architecture et mesures : https://github.com/NourMontacer01/Retrieval-Augmented-Generation-ai-law-assistant

> L'outil oriente dans les textes, il ne qualifie rien juridiquement.
